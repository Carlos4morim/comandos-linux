# comandos-linux
Este e um pequeno suporte para meus estudos de Linux 

feat: versão 1 do app de anotações de comandos Linux

App web em arquivo único (index.html) para registrar comandos Linux
estudados, com opções, descrições e exemplos. Pensado para uso no celular.

Funcionalidades:
- Lista de comandos com busca (comando, opção, descrição) e filtro por categoria
- Cadastro e edição de comandos com opções e exemplos
- Adição rápida de opções na tela do comando
- Importação por JSON com pré-visualização e mesclagem (não duplica
  comandos existentes; só acrescenta opções e exemplos novos)
- Exportação de backup em JSON
- Botão que copia o pedido pronto para a IA gerar o JSON no formato do app
- Dados salvos localmente no navegador (localStorage)

Fora desta versão: modo revisão, PWA/uso offline.
